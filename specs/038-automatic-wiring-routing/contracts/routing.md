# Routing and UI contract

Matrix Rebuild replaces managed key nets only. Preserve terminals/GPIO allocation and selected grid/cells; other editing operations retain their contracts. Accept only if getNets proves each requested key-pin belongs to its one intended terminal with no alien contact/encoder. Geometry stays orthogonal and finite; budgets enforced atomically. One output endpoint per used terminal, two vertical blocks per half. Rows are the inner block, columns the outer block; outward means left for unibody/left half, right for right half.

UI: existing Rebuild/preview summary/Apply/Cancel/Undo; text describes trees and two grouped outputs. Keyboard and themes unchanged; same explanation in onboarding wiring step. No new controls or motion.
