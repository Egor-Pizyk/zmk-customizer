## Boundaries

Chromium runs all rows. Firefox/WebKit run engine-sensitive tagged cases: rotated resize, all rotation zones, pan/zoom, numeric native controls, cancellation/stale state, keyboard/dialogs and compact paint. Full product/export lifecycle remains Chromium + existing engine-independent unit/golden contracts. Native OS pointercancel sources, screen-reader speech, hardware, all zoom/key-size combinations, all themes and every responsive size are not exhaustive. Capture cancellation here is native SVG removal during an active real mouse gesture; no synthetic pointercancel is injected.
