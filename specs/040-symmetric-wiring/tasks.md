Tests-first обязателен для domain/storage/generators и регрессий. Unit expected values не вычисляются проверяемой функцией. Browser coverage использует реальный production app/provider/Worker и настоящий Open/Save/ZIP. Этот документ — единственная requirement → task → check → evidence mapping; фактические receipts живут в verification.md и ссылаются на ID задач.

## Format

`- [ ] Txxx Описание задачи с путём и проверяемым результатом.`

`[P]` разрешает независимую работу только после указанных prerequisites и при отсутствии shared-file conflicts. Отметки выполнения ставятся только по evidence; подготовленная спецификация/план не являются выполнением production задач. Setup/foundation не создают новый проект или лишние папки. Новые test paths создаются при реализации, existing owners переиспользуются.
