# Firmware data

Project schemaVersion8: `firmware: Readonly<Record<string, boolean | number | string>>`. Empty record means applicable defaults. v7 migration adds empty firmware preserving unrelated bytes semantically; v1–v6 chain through it. Record limited to128 entries, keys uppercase identifiers max96 chars, strings max1024 at parse boundary; finite numbers. Unknown options and invalid primitive kinds load with domain issues for repair. Arrays/objects/null reject. Catalog discriminated `kind` bool/int/enum/string, identity CONFIG symbol (enum identity is choice group without emitted CONFIG), `default`, description, category, docsUrl, requirement tuples, hardware availability and central routing. No catalog facts in UI/domain. Defaults can use board BLE capability supplied by caller.
