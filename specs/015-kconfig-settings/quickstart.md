# Validate Firmware settings

Run `make check`, production build, `make test-e2e`, focused firmware browser scenarios three sequential times and `make zmk-build` as documented in docs/commands.md. In an isolated browser import a valid macropad project; open Firmware; change all four control types; Undo/Redo, reload and download/open JSON. Search a symbol. Commit invalid debounce; observe Firmware badge, inline/Problems errors and disabled ZIP. Activate the issue while search hides it; focus must reach field. Repair/reset and download ZIP; compare sorted non-default config with preview. For split with central settings, inspect left/right user conf files and absence of shared conf. Manual gate additionally requires authorized keyboard-only, screen reader, zoom, dark/reduced-motion inspection from docs/guidelines/frontend/accessibility.md.
