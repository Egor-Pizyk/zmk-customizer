# Firmware contracts

Inventory: ZMK_WPM; ZMK_HID_REPORT_TYPE (HKRO/NKRO); ZMK_HID_CONSUMER_REPORT_USAGES (FULL/BASIC); ZMK_HID_INDICATORS; ZMK_HID_SEPARATE_MOD_RELEASE_REPORT; USB_DEVICE_MANUFACTURER; ZMK_USB_BOOT; ZMK_BLE_CLEAR_BONDS_ON_START; ZMK_BLE_PASSKEY_ENTRY; ZMK_IDLE_TIMEOUT; ZMK_SLEEP; ZMK_IDLE_SLEEP_TIMEOUT; ZMK_KSCAN_DEBOUNCE_PRESS_MS; ZMK_KSCAN_DEBOUNCE_RELEASE_MS; ZMK_BATTERY_REPORTING; ZMK_BATTERY_REPORT_INTERVAL; BT_BAS; ZMK_SPLIT_PERIPHERAL_HID_INDICATORS; ZMK_SPLIT_BLE_CENTRAL_BATTERY_LEVEL_FETCHING; ZMK_SPLIT_BLE_CENTRAL_BATTERY_LEVEL_PROXY. Every identity starts CONFIG_ in saved overrides, including choice identity. No raw Kconfig. Labels/descriptions/units/dependencies/default/docs remain visible per row. Reset removes override; unavailable non-default overrides remain repairable.

Integers: debounce -1..1000ms; idle 0..2147483647ms; sleep 1..2147483647ms; battery interval1..86400s. These are product bounds. USB manufacturer one-line nonempty ≤64 UTF-8 bytes. Dependency overridden away from default fails until prerequisite enabled/reset; never silently changes another option. Unknown values resettable.

Output: CONFIG symbols sorted, only non-defaults, enums emit selected member=y, strings escape backslash/quote, LF/trailing newline. For central-only split settings produce config/name_left.conf and name_right.conf and omit config/name.conf. Common overrides on both; central-only on left. Existing pure shield output can use common conf; repository is packaging authority for split routing.

Browser coverage: native bool/int/enum/string + undo/redo/reload (risk lost state; assert UI and saved JSON); out-of-range repair and filtered issue navigation (risk blocked inaccessible repair; assert badge/focus/disabled download/recovery); actual ZIP sorted config (risk mismatched preview; compare bytes and filenames); split central routing (risk peripheral build warning; compare both per-half files). Existing tests protect base export/wiring. Native number/focus cases also Firefox/WebKit. Sensitivity: temporarily suppress setting operation and demand persisted-value assertion failure; exact restoration.

USB boot and USB manufacturer overrides are central-only in split. Fetching requires peripheral battery reporting and BAS; conflicts are validation errors. Build verification must consume exported config files through build.yaml targets and assert resulting .config values, including central-only absence on right.
