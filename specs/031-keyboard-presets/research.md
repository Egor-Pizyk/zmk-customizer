## Geometry adaptation found by validation

The original Corne v0.3 pitch rectangles overlap between keys 29/30 and rotated thumbs. The Customizer preset translates all six thumb keys and their rotation origins down by exactly 0.25u; The right half and its active rotation origins also move right by 0.25u so the two inner rotated thumb rectangles do not intersect. Widths, heights, angles and within-half main-row geometry remain from upstream. The preview description names the extra clearance. This is a custom-layout starting point, not a PCB template. Independent upstream fixtures remain untouched. Domain validation must report no geometry/name/binding issues for any library entry; only unwired contacts are expected.

Sofle's QMK LAYOUT lists 60 positions including two encoder push buttons (source indices 42/43). This keys-only 58-key variant omits those positions, while retaining the source geometry/order of the other 58 keys.

## Lily58 correction — 2026-10-20

The original QMK source cited above has no thumb rotation metadata; it is insufficient for the physical angles. Pinned ZMK v0.3.0 geometry supplies the missing two 30° rotations and corrected positions:
https://github.com/zmkfirmware/zmk/blob/edf5c0814fd3ea202e43aad2d68fd32e882a518c/app/dts/layouts/kata0510/lily58.dtsi . Thumb index 53: x=5.75u, y=4u, 1×1.5u, +30°, origin (6.25,4.75)u; index 54: x=9.75u, y=4u, −30°, origin (10.25,4.75)u. Existing column stagger retains the original QMK precision rather than rounding 0.375u/0.125u to ZMK's centi-u values. Existing inner keys at (6,2.75)u and (9.5,2.75)u and all key order/bindings are preserved.

Compared the source with the author's original and Pro PCB files at commit `58c649797c185b7b32b9928d4546665153cfacfd`: https://github.com/kata0510/Lily58/blob/58c649797c185b7b32b9928d4546665153cfacfd/pcb/Lily58.kicad_pcb and https://github.com/kata0510/Lily58/blob/58c649797c185b7b32b9928d4546665153cfacfd/Pro/PCB/Lily58_Pro.kicad_pcb . Both place the angled SW26 footprint at (105,127)mm with KiCad rotation 300°, while adjacent bottom keys are staggered (SW27 at 130,126; SW28 at 149,123.75; SW29 at 168.1,123.75). PCB footprint orientation and keycap long-axis orientation are different conventions; the explicit ZMK physical-layout cells provide the application's keycap rotation values.

The exact ZMK pitch rectangles overlap neighboring keys under this application's full-pitch overlap validator (confirmed by the unchanged all-presets invariant test). As with Corne, retain validation and explicitly adapt clearance: translate the left angled thumb and its origin +0.125u in X, the right −0.125u in X, without changing Y/angle/size or any other key. Final x/origin pairs: 5.875/6.375 and 9.625/10.125. The preset description discloses extra inward clearance. This is an editable layout starting point, not an exact PCB/keycap outline. No generator syntax, runtime fetch, schema or existing saved project changes.
