# Logical folder organization

Separate all Vitest tests from production source files and group crowded source folders by responsibility. Preserve current behavior, generated bytes, public names, existing work in progress, layer boundaries, coverage floors, fixtures and browser snapshots. Test paths mirror production groups in tests/unit. Tooling and active architecture documentation must use the new paths.

Acceptance: no *.test.ts(x) remains in src; production groups have descriptive names; imports resolve; make check, production build and existing browser suite pass. No new user journeys or E2E assertions are required because this refactor only changes file locations and module specifiers.
