# Validation

1. Start with two keys and a wire. Toggle pin 1 diode; pin 2 is unavailable. Remove and add at pin 2.
2. Use Parts with keyboard only to add, remove and reverse; verify the cathode bar and text agree.
3. Move the key; wires remain attached and diode follows. Undo/redo each change.
4. Save/open/reload: diode pin/polarity preserved. Open v1/v2/v3 files: no inserted diodes.
5. Delete key: diode disappears. Inspect both themes and 200% zoom; use Parts below 50% canvas zoom.
6. Run make check. Firmware preview remains a placeholder until shield-generators.
