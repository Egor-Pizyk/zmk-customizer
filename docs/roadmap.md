# Product direction

The running app and meaningful tests describe implemented behavior. This roadmap is product context, not a numbered implementation queue or an approval gate.

Current product areas: keyboard presets/KLE import and physical layout; controller/encoder configuration; electrical wiring and protected atomic proposals; layers, behaviors, combos/macros; firmware settings; versioned projects and deterministic ZMK export; interactive onboarding. Changes must preserve stable identities, user data, Undo/Redo, keyboard access and pinned ZMK v0.3 output.

Future directions, not automatically authorized implementation:

- [Mechanical design](roadmap-2.0.0.md): enclosure, mounting, plates and assembly components. [Research](research/2.0.0-discovery.md) and [component sources](research/2.0.0-component-sources.md).
- [Keycap generation](roadmap-3.0.0.md): product questions and reference projects.

Work directly from the user's requested change. Investigate material product/technology uncertainty when it affects the next decision; no Spec Kit stages, reserved feature numbers or mandatory artifact sets.
